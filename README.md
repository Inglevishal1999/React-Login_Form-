# React Login & Signup Form

This project demonstrates how to build a **Login and Signup form in React.js** with the ability to toggle between the two forms. It is designed to help beginners understand **state management, conditional rendering, and form handling** in React.

---

## 🚀 Features
- **Login & Sign Up Toggle** – Switch between login and registration forms with a single button.
- **Conditional Fields** – Extra fields like *Full Name* and *Confirm Password* appear only in signup mode.
- **Form Handling** – A single `handleSubmit` function manages both login and signup.
- **Responsive UI** – Built with Tailwind CSS for a modern and responsive design.

---

## 🛠️ Tech Stack
- **React.js** – Frontend framework
- **Tailwind CSS** – Styling and layout
- **JavaScript (ES6+)** – Logic and functionality
